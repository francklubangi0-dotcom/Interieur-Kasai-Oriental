# nod.jc

Portail institutionnel francophone, pensé comme une porte d’entrée claire vers les actualités, programmes, ressources et services publics.

## Démarrage

```bash
npm run dev
```

Le serveur écoute sur le port `3000` par défaut et sert le dossier `public/`. Le site est volontairement léger : HTML sémantique, CSS responsive et JavaScript natif, sans dépendance externe.

## Direction d’interface

L’expérience reprend les repères du site de référence `https://sante.gouv.cd/` — en-tête institutionnel, navigation principale, accès rapides, liens utiles et pied de page — avec une identité propre à nod.jc : bleu nuit, vert menthe et une mise en page éditoriale plus aérée.
